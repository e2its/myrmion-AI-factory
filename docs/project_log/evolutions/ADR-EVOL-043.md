# ADR-EVOL-043: Governance corpus in layers

## Context

Issue #52, axis D of the 2026-09 evolution (#50). Two failures measured in the reference implementation and reproduced here before design: (1) the corpus outgrew its injection points — the snapshot embedded ~37 KB of law bodies and the harness delivered a truncated preview while every size self-check stayed green (it measured the file, not what the session received); (2) a rule with two bodies drifts — stateless, privacy and branching existed both in the constitution template and in a rule file, with the branching pair contradicting each other ("2 approvals" vs `{{PR_APPROVAL_COUNT}}`). Verified on this repository: five PreToolUse hooks printed BLOCKED to stdout and exited 1 — a non-blocking error under the Claude Code contract, so none of them blocked and the push gate let a failed preflight through; the measurement reader (EVOL-042) counted 41 pre-edit firings emitting 8 938 B and delivering 0 B; the snapshot's DC extractor expected `### DC-` blocks while the catalog was a table, so every real project received 0 universal DCs; no script resolved applicability (the Roll-Call was LLM pseudocode reading a context file nothing wrote). Decision authority delegated by the user on 2026-09-25 ("las rdrs son tuyas hasta el final"; "recuerda dry a kiss"; "es una meta framework que se materializa en setup").

## Decision

Agent-internal choices (pick + surviving risk):

- **One shape for every law, three lines.** `[ID] Title` / `> sentence` / `Body: pointer · Records: ids`. The constitution template becomes the index of project law (`[PLAW-01..13]`, 848 → 70 lines); `CLAUDE.md § Governance Rules` becomes the index of universal law on both lock-step sides (`[LAW-15]` joins the corpus). Every body lives once — a rule file, a skill or an instruction — under a heading that quotes the sentence byte-identically; the same reader that builds the snapshot verifies the pair. Risk: a body moved to a skill is delivered by factory-sync, not SETUP; the synthetic materialiser copies the framework tree the way sync does and checks every pointer in the scratch project.
- **One reader, one package.** `scripts/gate.py` + `scripts/gates/*.py` (stdlib; PyYAML when present, strict subset parser otherwise) parse the index, the catalog and every `applicable_when`; resolve applicability; build the digest; measure budgets; run the ratchet; emit the pre-edit envelope. Hooks, the snapshot generator, the parity gates and the pre-flights all call it. Lock-step pairs meta ↔ template. Rejected: bash + awk per consumer (the drift this axis cures came from four awk parsers of the same shape).
- **Hook channel per the documented contract.** Block = exit 2 + stderr; context = `hookSpecificOutput.additionalContext`; plain stdout from a PreToolUse hook is never delivered. `scripts/test-hooks.sh` feeds every shipped hook its red payload and asserts channel, exit code and envelope. New hook `deliver-governance.sh` (tier 5): families, classes and rule pointers governing the file being written, within `budgets.pre_edit`, deduped per session. Risk: the envelope field is documented under the standard decision model, not in a per-event table; the measurement reader reports delivered bytes per hook, so a channel regression is visible in the numbers.
- **Budgets are keys, measured on the real producer.** `config/quality.json → budgets` (session_start, prompt_submit, pre_edit, snapshot, law_sentence_max_chars, dc_invariant_max_chars); `gate.py budget` runs the banner, onprompt under `GOVERNANCE_ONPROMPT_WORST_CASE=1`, the delivery hook on the path that matches the most globs, and reads the snapshot bytes; missing key or overflow is red; the generator itself exits 3 when the lite profile overflows. Rejected: a byte limit read from the harness (undocumented).
- **Families, not prose.** The catalog is a families table (surface globs + one-line invariant) and a 7-column class table (family, invariant, gate, paths, agents, severity); narratives moved verbatim to `defect-prevention-cases.md`. The snapshot embeds only the families; classes are delivered at the point of edit by path. SETUP's 22 stack DCs render in the same shape.
- **Two-tier ceremony, gated both ways.** `check-adr-constitution-sync.sh` direction B: a `> sentence` (or a `CLAUDE.md` corpus line) changing without an ADR landing accepted in the same diff fails; pointer, records and preamble edits are free; body edits need only the manifest bump. The Accept Procedure of `factory-adr-management` writes the sentence to the index and the body to `body_home`; `scripts/test-adr-accept.sh` pins it with ADD / REPLACE / two refusals before any write.
- **Retired vocabulary is a key.** `config/quality.json → retired_terms` (term, record, exemptions); `gate.py retired-terms` scans the coherence root sets with history classes exempt. Seeded with this axis's three retirements; the ratchet found four live occurrences during the build and each was fixed rather than exempted.
- **Lite snapshot only; full on demand.** `--profile full` appends bodies and the class table for review; it is never injected. Rejected: keeping the verbatim law dump under a bigger budget — the measured cause was the dump.
- **The synthetic materialiser is the epic's smoke.** `scripts/materialize-synthetic.sh` lands the manifest targets with sample answers, copies the framework tree, then runs the generator, the resolver, pointer parity, budgets, the ratchet, hook delivery and the banner in the scratch project. It found three real gaps during the build (five rule files and the new hook missing from the manifest, the catalog still targeting the retired path) before any human would have.

## Consequences

- BREAKING for materialised projects: `docs/constitution.md` shape (index) and `.claude/rules/defect-prevention.md` shape (families); `SETUP --upgrade` migrates through the manifest (MAJOR entries). Five new rule files (`project-mode`, `configuration`, `i18n`, `documentation`, `dependencies`), the cases annex, the `gates` package, the delivery hook.
- `framework_version` 6.3.0 → **7.0.0** (MAJOR; branch `feature/EVOL-043-governance-corpus-layers`).
- LAW-01 sentence amended (two-tier ceremony); LAW-15 enters the corpus; every universal law re-expressed as index + body. Universal H2 sections untouched; `law_corpus_mirror` and `universal_clause_mirror` green.
- Later axes read the same package: coherence gates (#53) extend `corpus.body_section`; agents (#58) take `gate.py digest` at spawn; profiles (#55) add members next to `budget` and `retired-terms`.

## Alternatives considered

Keep bodies in the constitution and raise the budget — rejected: the truncation was the symptom, the second body the disease. A YAML corpus instead of markdown — rejected: agents read markdown, and the index is three lines. PreToolUse `permissionDecision: deny` JSON instead of exit 2 — kept as a valid form but not used: exit 2 + stderr is one line in bash and the test proves it. Per-agent hand-written rule lists — rejected by the issue and by the measurement (30 of 31 files loaded → 18 resolved).

## Operational Rule

Amendment shipped in this PR: `CLAUDE.md § Governance Rules` (meta) and its mirror in the project `CLAUDE.md` template take the index form — one sentence, one `Body:` pointer, `Records:` per law; `[LAW-01]` sentence now states the index and the two-tier ceremony; `[LAW-15]` joins the corpus. Project law index shape shipped in `constitution_template.md` (`[PLAW-NN]`).
